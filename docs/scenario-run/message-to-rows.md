# Message to rows

Decision 2's evidence. The THR010 driver (two open trips) writes "I will be late by 45 minutes.". Below is every row that conversation left in Postgres, the system of record, read back after the scenario run. Generated by `scripts/scenario-run.sh`.

1. **The phone, not the text, finds the driver.** The agent asks the planner for that phone's open trips, gets two, and asks which one. It does not guess.
2. **The pick binds the conversation** to SHP1020 and to its thread (THR-BF0FE991-9845). Every later call is about that shipment, and the model never chooses it.
3. **The delay becomes structured rows.** The exception, the driver's ETA and, if the driver changes slot, the hold and the booking it replaces.
